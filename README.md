# VoiceClip Android

Hlasové zadávanie textu pre Android: ťukneš na plávajúcu ikonku, nadiktuješ a prepísaný text sa vloží na kurzor alebo do schránky.

## Stiahnuť

[Stiahnuť voiceclip-android.apk](https://github.com/enthilza/voiceclip-android-releases/releases/latest/download/voiceclip-android.apk) · [Všetky vydania](https://github.com/enthilza/voiceclip-android-releases/releases)

Android 8.0 alebo novší.

## Inštalácia

1. Otvor odkaz vyššie na telefóne a stiahni APK.
2. Pri prvej inštalácii povoľ „Inštalovať neznáme aplikácie“ pre prehliadač alebo správcu súborov.
3. Ďalšie verzie si aplikácia nájde sama: kontroluje ich raz denne pri štarte a na požiadanie tlačidlom Skontrolovať aktualizácie.

Verzia pre Windows je v repozitári [VoiceClip](https://github.com/enthilza/VoiceClip).

Tento repozitár obsahuje iba zostavené APK, nie zdrojový kód.
